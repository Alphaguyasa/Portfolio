03About

I came to the web through breaking things.

Capture-the-flag taught me how software actually fails: in the gap between what a developer assumed and what a user can do. Winning first place at Haramaya University's CTF — run with INSA, Ethiopia's national cyber authority — changed how I write code, not just how I read it.

Now I build the other side. Frontends that validate before they trust, components that behave the same on the tenth interaction as the first, and interfaces that stay legible on a slow connection in Harar as well as a fibre line in Addis.

Alongside that I led the university's Cyber Club — teaching, running sessions, keeping a group of people curious — and worked as the focal person for Leyu data collection at Gheero, which is where I learned that clean data is a design problem before it's an engineering one.
